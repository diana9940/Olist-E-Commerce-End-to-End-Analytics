# Olist Business Discovery

An end-to-end data project using the **Brazilian E-Commerce Public Dataset by Olist** to identify business problems and turn raw e-commerce data into actionable insights.

## Dataset

The project uses the Olist Brazilian E-Commerce dataset containing information about:

* Orders & Order Items
* Customers
* Products
* Sellers
* Payments
* Reviews
* Geolocation
* Product Categories

**Dataset:** https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Project Objective

The goal is to explore the business performance of an e-commerce platform, identify key issues and patterns, and support data-driven business decisions.

## Tools & Technologies

* **Python:** Data cleaning & preparation
* **SQL Server:** Business analysis & insights
* **Power BI:** Interactive dashboard & visualization

## Workflow

```text
Raw Data
   ↓
Python Data Cleaning
   ↓
SQL Database & Analysis
   ↓
Business Insights
   ↓
Power BI Dashboard
   ↓
Business Recommendations
```

## Data Preparation

The datasets were cleaned and validated using Python, including:

* Handling missing values
* Converting date columns
* Removing duplicate records
* Validating data consistency
* Checking business-related data quality issues

## SQL Analysis

SQL was used to investigate:

* Sales & revenue performance
* Customer behavior
* Product & seller performance
* Delivery performance
* Customer reviews & satisfaction

## Power BI

The final dashboard presents the most important business KPIs and insights in an interactive format, helping stakeholders understand performance and identify areas that require attention.

## Key Outcome

The project moves from **raw e-commerce data → data quality → business analysis → insights → actionable recommendations**, demonstrating an end-to-end data-driven problem-solving approach.
